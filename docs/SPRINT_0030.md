# Sprint 0030 - Administración Institucional

## Objetivo

Iniciar la fase de institucionalización de SIGD-ST mediante parámetros configurables.

## Parámetros implementados

- Ejercicio.
- Valor UC.
- Norma UC.
- Fecha de vigencia UC.
- Distrito.
- Localidad.
- Organismo.
- Próxima disposición.

## Integración

El generador de disposiciones deja de depender de la norma UC y del valor UC embebidos en el código. Toma ambos desde Administración.
